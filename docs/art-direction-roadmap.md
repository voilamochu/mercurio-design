\# Mercurio — Art Direction Roadmap



\## Purpose



This document defines the long-term visual direction for Mercurio.



The original standalone web application was created purely for playtesting and intentionally uses minimal placeholder visuals. The goal of this roadmap is to transform Mercurio into a premium board game experience suitable for BoardGameArena and future physical production.



The philosophy is:



> Every component should feel like a professionally illustrated board game component rather than software UI.



Artwork, layout and information hierarchy should work together. Every component should contain three conceptual layers:



1\. Artwork

2\. Premium UI / Frame

3\. Gameplay Information



Planet cards established the quality bar for the project. Every remaining component should target a similar level of finish.



\---



\# Visual Principles



\## Physical-first design



Every component should resemble a physical board game component.



Rather than designing software panels, ask:



> "What would this object look like if Mercurio were published by Garphill, Mindclash, Eagle-Gryphon or Stonemaier?"



\---



\## Illustration-first



Artwork should exist on every major component.



Artwork should establish atmosphere without interfering with readability.



\---



\## Layered Composition



Where practical, components should be assembled from reusable layers:



\- Background artwork

\- Decorative frame

\- Gameplay overlays

\- Icons

\- Text



This mirrors the successful pipeline established for Planet Cards.



\---



\## Reusable Systems



Prefer reusable visual systems over bespoke artwork.



Examples:



\- shared frames

\- decorative borders

\- banners

\- slot graphics

\- title bars

\- ornamentation



These should be reused consistently across the project.

\# Programmatic Elements



The following should remain programmatically rendered rather than becoming artwork:



\- Reputation Track

\- Favour Track

\- Synergy Track

\- Player counters

\- Credit counters

\- VP counters

\- Dynamic highlights

\- Selection borders

\- Empty slots

\- Card counts



These are dynamic gameplay elements and are better handled using SVG/CSS.



\---



\# Design Pipeline



Each major component should follow the same production workflow.



1\. Concept

2\. Artwork generation

3\. UI frame design

4\. Shared component extraction

5\. Procedural renderer

6\. Automated generation

7\. Visual review

8\. Iteration

9\. Export pipeline

10\. Integration into BGA



Planet Cards established this workflow successfully and should serve as the template for future asset production.

\# Long-Term Vision



Mercurio should ultimately feel like a premium modern Eurogame.



The objective is that every screen on BoardGameArena should resemble a beautifully photographed tabletop rather than conventional software.



Artwork should create atmosphere.



UI should communicate gameplay.



Neither should dominate the other.
